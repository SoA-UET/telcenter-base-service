# A32 Group

This is the group of APIs between
the [Partner's File Importing Service](../services/partner/S15_File_Importing_AI_Agent.md)
and [Partner's Knowledge Update Service](../services/partner/S12_Partner_Knowledge_Update_Service.md).

This API consists of 1 API.

## A32

This API is based on RabbitMQ.

The API has 1 method.

### A32 Method: `forward_parsed_data`

Request body format:

```json
{
  "method": "forward_parsed_data",
  "params": {
    "source": "Viettel",
    "file_name": "viettel_services_2024.xlsx",
    "file_size_kb": 245,
    "data": [
      {
        "Mã dịch vụ": "SD70",
        "Thời gian thanh toán": "Trả trước",
        "Các dịch vụ tiên quyết": "",
        "Giá (VNĐ)": 70000,
        "Chu kỳ (ngày)": 30,
        "4G tốc độ tiêu chuẩn/ngày": 1,
        "4G tốc độ cao/ngày": 0,
        "Gọi nội mạng": "",
        "Gọi ngoại mạng": "",
        "Tin nhắn": "",
        "Chi tiết": "",
        "Tự động gia hạn": "Có",
        "Cú pháp đăng ký": "SD70 DK8 gửi 290"
      }
    ],
    "records_count": 150
  },
  "id": "import-1234"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": {
            "accepted": true,
            "records_received": 150,
            "processing_started": true
        }
    }
}
```

On success, the content includes:
- `accepted`: Boolean indicating if the data was accepted for processing
- `records_received`: Number of records received
- `processing_started`: Boolean indicating if processing has started

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be:
- `"EMPTY_DATA"` - If the data array is empty or missing
- `"INVALID_DATA_FORMAT"` - If data format is malformed or doesn't match schema
- `"DUPLICATE_FILE"` - If the same file has already been processed recently
- `"UPDATE_SERVICE_UNAVAILABLE"` - If S12 service cannot be reached

## Queue Configuration

Default queue names (configurable via `.env`):
- Request Queue: `partner_file_import_requests`
- Response Queue: `partner_file_import_responses`
