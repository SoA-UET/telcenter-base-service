# A16 Group

This is the group of APIs between
the [Partner's Consultation Service](../services/partner/S13_Partner_Consultation_Service.md)
and [Partner's Local Knowledge Service](../services/partner/S11_Partner_Local_Knowledge_Service.md).

This API consists of 1 API.

## A16

This API is based on RabbitMQ.

The API has 1 method.

### A16 Method: `query_knowledge`

Request body format:

```json
{
  "method": "query_knowledge",
  "params": {
    "query": "Gói cước 4G có giá dưới 100,000đ và data trên 2GB/ngày",
    "filters": {
      "source": "Viettel",
      "max_price": 100000,
      "min_data_per_day": 2
    },
    "max_results": 5,
    "include_similar": true,
    "consultant_id": "consultant-456",
    "session_id": "session-789"
  },
  "id": "query-1234"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": {
            "results": [
                {
                    "Mã dịch vụ": "ST70",
                    "Thời gian thanh toán": "Trả trước",
                    "Giá (VNĐ)": 70000,
                    "Chu kỳ (ngày)": 30,
                    "4G tốc độ tiêu chuẩn/ngày": 2,
                    "4G tốc độ cao/ngày": 0,
                    "Gọi nội mạng": "Miễn phí",
                    "Cú pháp đăng ký": "ST70 gửi 191",
                    "relevance_score": 0.92
                },
                {
                    "Mã dịch vụ": "V90",
                    "Giá (VNĐ)": 90000,
                    "4G tốc độ tiêu chuẩn/ngày": 3,
                    "Cú pháp đăng ký": "V90 gửi 191",
                    "relevance_score": 0.88
                }
            ],
            "total_results": 2,
            "query_time_ms": 85
        }
    }
}
```

On success, the content includes:
- `results`: Array of matching telecom services with relevance scores
- `total_results`: Total number of results found
- `query_time_ms`: Time taken to process the query

Each result includes all available service fields plus a `relevance_score` (0-1) indicating how well it matches the query.

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be:
- `"EMPTY_QUERY"` - If the query string is empty or missing
- `"INVALID_FILTERS"` - If filter parameters are malformed
- `"KNOWLEDGE_BASE_UNAVAILABLE"` - If the local knowledge database cannot be accessed
- `"NO_RESULTS_FOUND"` - If no matching results are found (this is a soft error)

## Queue Configuration

Default queue names (configurable via `.env`):
- Request Queue: `partner_knowledge_query_requests`
- Response Queue: `partner_knowledge_query_responses`
